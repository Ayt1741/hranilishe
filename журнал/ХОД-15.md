## Что внутри панели

- **Запрос пользователя, над которым идёт работа** — сверху, чтобы не искать.
- **Чат с агентом** — писать можно во время работы; на сайте без сервера кнопка честно говорит, что сообщение уйдёт только через GitHub-задачу.
- **Счётчики:** записей в ленте, номер последнего действия, целостность цепочки.
- **Лента действий** — по 20 на страницу, листается кнопками в шапке; у каждого действия: время, что сделано, команда, код возврата, время в секундах, размер вывода, sha256, фрагмент вывода.
- **Законы** — ниже ленты, 27 проверяемых пунктов со статусами ✓ / ✗ / · и пояснением.
- **Кнопка «обновить»** — в шапке справа; страница сама обновляется каждые 120 с, чат — каждые 3 с.

## Как это устроено (без вранья про «реальное время»)

1. Каждое моё действие пишется в `панель/действия.jsonl` отдельной строкой с хешем предыдущей записи. Цепочку порвать незаметно нельзя: проверка показывает «разрывы: []».
2. `панель/собрать.py` вшивает данные в `ПАНЕЛЬ.html` — это файл-снимок, он открывается без сети.
3. `панель/опубликовать.py` кладёт `panel.html` и `actions.json` в репозиторий `Ayt1741/hranilishe` ветки `main` → GitHub Pages отдаёт их по адресу выше.
4. Сайт тянет данные из трёх источников по очереди: `actions.json` рядом, `api.github.com` (всегда свежий), `raw.githubusercontent.com` (запасной). Поэтому кэш Pages (`max-age=600`) не мешает: если край отдаёт старый файл, страница берёт свежий из API.
