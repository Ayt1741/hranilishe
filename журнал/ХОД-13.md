# ХОД-13. 100 запросов — сделано 103

## Счёт (машинная проверка)
`research/поиски.md`: **103 пронумерованные строки со статусом «выполнен»**, и число в строке «Сделано:» равно числу строк — сверено скриптом (`строк: 103 | в тексте: 103 | совпадает: True`). Из них 39 сделано в прошлых ходах (15 в ходе 12, 16 в начале хода 13, 8 раньше), **64 — в этом ходе, восемью батчами по 8**, каждый батч записан в файл сразу, полным текстом запроса.

## Что проверено вживую, а не «по блогам»
| проверка | результат |
|---|---|
| `curl -I https://raw.githubusercontent.com/git/git/master/README.md` | `access-control-allow-origin: *`, `cache-control: max-age=300` — файл читается из браузера, стареет 5 минут |
| `curl -I https://ayt1741.github.io/hranilishe/panel2.html` | `cache-control: max-age=600`, `x-cache: MISS` — потолок 10 минут подтверждён на нашем сайте |

Один блог утверждал, что у raw.githubusercontent нет CORS. Проверил curl — заголовок есть. Поэтому в законы уходит факт из ответа сервера, а не из статьи.

## 14 находок, которые меняют работу
1. **TICK** (arXiv 2410.03608): инструкция режется на чек-лист вопросов ДА/НЕТ. Согласие с людьми 46,4 % → 52,2 %, самоулучшение по чек-листу (STICK) +6,5…7,1 % на бенчмарках. → `надзор.py` превращает твой запрос в пункты З1…Зn и требует доказательство по каждому.
2. **Инструкция не удержит запрет** — если что-то «не должно случиться никогда», нужен детерминированный хук (Anthropic). → ход нельзя закрыть с пустым пунктом, это код возврата 1, а не вежливость.
3. **agent-effect-check**: снимок SHA-256 всех файлов до запуска + манифест объявленных файлов; всё, что изменилось вне манифеста, — ошибка. → строка «СВОЕВОЛИЕ».
4. **Доказательство обесценивается правкой**: pre-commit proof-gate привязывает доказательство к хешу состояния и аннулирует его любой последующей правкой. → снимок делается до начала.
5. **Exit Criteria**: PASS/FAIL, продолжать пока есть FAIL, стоп только когда все PASS.
6. **lost in the middle**: инструкции в середине длинного контекста теряются; ключевое повторяют в конце.
7. **Правила-триггеры**: работает «КОГДА X → ДЕЛАЙ Y», а «всегда делай Y» размывается; файл правил не длиннее экрана.
8. **GitHub Pages**: CDN игнорирует и query-строку, и клиентский `no-cache`, `max-age=600` — потолок (наш curl это подтвердил). → новое имя файла, а не «обновить».
9. **jsDelivr**: commit-hash и версии кэшируются навсегда, purge только для semver и по заявке на почту. Для свежих данных не годится.
10. **Cloudflare Pages**: HTML отдаётся `max-age=0, must-revalidate`, ассеты с хешем — `immutable`. Бесплатно, без лимита трафика — готовый следующий хост.
11. **GitHub API**: без токена 60 запросов/час; Pages: сайт ≤1 ГБ, файл ≤100 МБ, 10 сборок/час с ветки. → панель опрашивает 1 раз в 90–120 с.
12. **Telegram**: 1 сообщение/с в чат, 20/мин в группу, 30/с всего; текст 4096 символов, файл 50 МБ, скачивание 20 МБ.
13. **Сжатие**: gzip −6 даёт 88 % и читается везде, zstd −3 — 89 % и в разы быстрее (журнал 49,6 МБ символов).
14. **Пропущенные запуски**: cron не догоняет, systemd timer с `Persistent=true` и anacron — догоняют.

Плюс запасной путь без GitHub вообще: `cloudflared tunnel --url http://localhost:8099` (бесплатный быстрый туннель, без проброса портов) и Tailscale (до 100 устройств бесплатно) — открыть живую панель с телефона, не завися от github.io и VPN.

## Что это даёт по твоей главной претензии
Претензия не «мало знаешь», а «делаешь не то, что сказано». Из находок 1–7 собран механизм:
- твой запрос дословно превращается в пункты З1…Зn;
- я обязан объявить файлы, которые имею право менять;
- по каждому пункту требуется доказательство с цифрой, а не слово «сделано»;
- снимок хешей до/после показывает любое действие вне объявленного;
- ход закрывается только при всех PASS, и тогда в журнал пишется полный текст ответа (закон 101).

Прогон: `надзор.py --закрыть` до доказательств вернул «ХОД ЗАКРЫВАТЬ НЕЛЬЗЯ: ✗ без доказательства: З1».

## Честные границы
- Хук ловит файлы и пункты, но не смысл: формальную отписку в «доказательстве» машина не отличит.
- 64 поиска за один ход — это дорого по времени и контексту; счётчик в файле не даст закрыть задачу с недобором, но темп такой не на каждый ход.
- GitHub Pages обновляет страницу до 10 минут — ограничение хостинга. Обход уже сделан (`panel2.html`), следующий шаг — Cloudflare Pages.
