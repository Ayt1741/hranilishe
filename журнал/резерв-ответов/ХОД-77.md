# ХОД 77 — ОТВЕТ ЗАКАЗЧИКУ

**Свидетель обрезания на восстановленной машине молчал дважды: точки не было в архиве, а без ключа прибор сдавался. Теперь обрезание ловится и без ключа — проверено подложным обрезанием (№807).**

## Что было

Ход 76 показал на чистой машине «пропущено 1» — пункт точки. Точка Меркла ловит **обрезание**, которого цепь хешей не видит по устройству. На восстановленной машине точки в архиве нет (только прибор), на GitHub она есть (2140), журнал тоже 2140 — а без ключа подписи прибор отвечал «НЕ ПРОВЕРЕНО», код 2, до сверки не доходил. Подложил обрезание 20 записей: код 2, не заметил никто (№807).

## Главное, что понял

**Корень Меркла считается без всякого ключа** (RFC 6962). Ключ нужен только для вопроса «правили точку или журнал». Обрезание и подмену видно и без него: журнал с GitHub (2140) даёт корень, **совпадающий** с точкой на GitHub, — сверка без ключа законна и опирается на свидетеля в репозитории.

## Честно про границы

Без ключа нельзя отличить «правили журнал» от «правили точку»: подделавший оба файла согласованно пройдёт. Защищает только подпись, а ключ по П6 в резерв не попадает. Закрыто надёжно другое: журнал и точку можно взять с GitHub и сверить между собой — это я и проверил (№808).
