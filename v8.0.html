Один раз вписать ключ

Ключ нужен, чтобы файлы уходили в твой Telegram. Он сохраняется только на этом телефоне, в странице его нет — украсть нечего.
Что нажать, по порядку:
1. Открой Telegram и найди бота @BotFather открыть @BotFather
2. Напиши ему /mybots — он покажет список твоих ботов. Нажми на своего бота.
3. Нажми кнопку API Token. Если вместо ключа написано, что он отозван — нажми Revoke current token, BotFather выдаст новый.
4. Скопируй строку из цифр и букв — вид 123456789:AAH…
5. Вернись сюда и нажми «Вставить из буфера», затем «Сохранить».
Публичный канал для ссылок на папки
Создай в Telegram новый канал, в названии любое имя, поставь ему публичный адрес (например @moy_disk), добавь нашего бота админом с правом «Публикация сообщений». Впиши адрес сюда — и ссылки на папки будут без ключа.
